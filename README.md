# Overview 
This is a lightweight React SPA intended to be a personal website
Features include: 
    - A Landing page that has a eye appealing UI -> main colours should be black and white -> Computer Modern font -> 
    - Resume (Previewable directly on the web app and also downloadable into pdf) Codebase should support Resume iteration (allow user to add change the resume.pdf file readily)
    - A Dropdown header should include option to direct user to another page: a project feature page 
        - Should have cards with the following displayable information 
            - Project name 
            - Project description 
            - Hyperlink to a website or porfolio 
            - Image previews (png format)
    a contact information page 
        - Container or panel with user's email and phone number
